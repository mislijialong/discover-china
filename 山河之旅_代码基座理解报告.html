挂钩点 为下一步迭代做的勘察

方向 A：多人异地联机房间服务端

  • 需抽离的「服务器权威状态」全部位于 Section 6 顶部全局变量：deck / publicTargets / players{node,score,tickets,secret,isAI} / currentPlayerIdx / hasRolled / pendingWilds——目前仅客户端内存可见。
  • 防作弊现状：AI 秘密城市 UI 已显示「??? 暗牌」，3D 秘密信标仅渲染 humanViewer 视角（sync3DBoardState）——视角过滤已有雏形；联网时需服务端做到不下发他人 secret/tickets，仅下发可见信息。
  • 状态机边界清晰：rollDice → pickWild → enterMovePhase → (onNodeClick|aiExecuteMove) → executeNodeMove → endTurn，很适合包成 action 消息；渲染层已按 humanViewer 视角工作，可复用为本地渲染层。
  • 建议：单文件保留「单人/热座」回退模式，另起独立 server 文件（Node.js 或 Python FastAPI + WebSocket）。

方向 B：Web Audio API 合成音效

  • 挂钩点明确：rollDice/animate3DDiceThrow（720ms 掷骰动画）、executeNodeMove 内每跳、公共目标得分处、获胜 alert 处；可选 pickWild / endTurn / UI 按钮。
  • 约束友好：振荡器+噪声合成，无外部音频资源，完全符合「不引入不稳定外部插件」；需处理 AudioContext 自动播放策略（用户手势后初始化/resume）。
