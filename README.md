# 🚂 山河之旅 (Discover China) — 线上版

中国地图火车旅行桌游《山河之旅》的线上 WebGL 实现。基于 **Three.js r128** 的单文件零构建依赖版本：49 城 83 边中国铁路网、5 色车票 + GO 万能票、无环全路径寻路与多路线选择、逐城分步跳跃动画、4K 离屏 Canvas 绘本底图（34 省真实省界、台湾/海南本岛、南海诸岛十段线附图框、定制矢量地标）。**v1.5 起支持免服务器的 P2P 在线房间联机（房主权威）。**

> 机制还原自 Yaofish（鳐鳐鱼）实体桌游《山河之旅 / My First Journey》：每回合投掷 2 颗定制六面木骰（5 色 + GO! 万能票），沿铁路网消耗车票逐城移动，途经公共目标得分，先攒满 10 分并返回自己的秘密城市者获胜。

## 快速开始

直接用浏览器打开 `index.html`（或仓库内任一游戏 html）即可游玩（`file://` 可运行，无需构建、无需安装）。打开后先进入**开始大厅**，可选择「本地游戏」或「在线多人」。

运行时依赖：
- Three.js r128（默认加载仓库内本地 `three.min.js`，缺失时自动回退 cdnjs CDN）
- 34 省 GeoJSON 省界（阿里云 DataV `100000_full.json`，加载成功自动叠加真实省界，失败回退手绘省界）
- 在线多人模式按需从 CDN 加载 Trystero / webConnect（P2P 信令库），首次连接稍慢属正常

### 玩法

1. 所有玩家从**北京**出发；
2. 投两枚六面骰（红/黄/绿/青/紫 + GO 万能）获得车票（可囤积）；
3. 沿铁路网消耗车票逐城移动（支持多路线选择、单回合连续换乘、途经顺路抢分）；
4. 途经或停留任意公共目标城市即时得分并补牌；
5. 先攒满 **10 分**并抵达自己的**秘密城市**者获胜。

### 在线多人（v1.5）

1. 在开始大厅切到「🌐 在线多人」，选择人数（2~4 人）并创建房间；
2. 把页面上的**房间码**或**邀请链接**发给朋友（邀请链接含座位令牌，刷新后可用同一链接顶回原座位）；
3. 所有玩家就位后房主点击「🚀 开始游戏」；
4. 游戏采用**房主权威**：访客把操作发给房主，房主校验回合与合法性后广播新状态；每个玩家只看到自己的秘密城市，其他人的秘密终点显示为 `??? (暗牌)`；
5. 房主刷新页面后可用原链接（`?host=1&room=...`）**恢复房间**，访客断线重连回原座位；任意玩家可在侧栏房间状态条点击「🚪 离开」。
6. 传输支持 Trystero / webConnect 双路线（默认自动选择），连接建立后邀请链接自动带上 `?p2p=` 参数保证全员同路。

## 核心特性

- **拓扑**：49 城 / 83 边 5 色无向铁路网；叶子节点仅呼伦贝尔、佳木斯；济南、重庆为度数 5 枢纽；东南沿海海上虚线航线（沪-台-高-港-澳-琼）
- **寻路**：受限深度无环全路径枚举（签名去重、每城最多 8 方案、按耗票数升序与顺路得分降序排序），多路线弹窗选择 + 悬停预览
- **动画**：逐城分步跳跃（440ms/跳 + 110ms 停顿）、高空抛投 3D 木骰、2D/3D 视图一键切换
- **渲染**：4096×4096 离屏 Canvas 矢量绘本（MeshLambertMaterial 消除高光过曝）；台湾/海南本岛含岛内分界，右下角标准《南海诸岛》十段线附图框
- **交互**：手写内联球面阻尼相机；铁轨悬停原色微增 + 端点棋子半透明防遮挡透视；2D/3D 切换
- **AI**：启发式寻路（目标优先 → 顺路得分 → BFS 距离贪心），支持 2~4 人随时切换真人/AI，全员 AI 时手动启停
- **音效（V7 / v1.3）**：零依赖 Web Audio 合成器——国风五声音阶旅途 BGM、骰子碰撞、GO 琶音、高铁双音风笛 + 白噪声气流、棋子连跳升调、得分琶音、10 分达标号角、胜利/惜败旋律；v1.3 新增胜负循环背景乐（胜利《山河凯旋曲》双音庆典 / 惜败余韵，结算弹窗实时切换与静音）；顶部一键开关 + 弹窗内 10 音效试听台
- **标签（v1.3）**：城市铭牌智能避让——49 城专属屏幕偏移 + 3 轮碰撞迭代（车站圆盘保护 + 标签互斥）+ 引线连接、悬停铁轨/路线时非相关标签半透明退让、棋子占位保护；三档显示密度（智能避让 / 仅关键城 / 悬停显示），顶部一键切换
- **在线多人（v1.5）**：免服务器 P2P 房间（Trystero / webConnect 双路线），5 位房间码 + 带令牌邀请链接，房主权威校验回合与路线合法性，广播式状态同步，秘密城市按座位脱敏（暗牌），房主 localStorage 断线恢复，访客重连顶回原座位
- **引导与体验（V7）**：5 步聚光灯新手引导（localStorage 记忆）、三页签规则弹窗、古风页内改名/胜负结算弹窗（替代原生 prompt/alert）、页内重新开局（替代刷新）
