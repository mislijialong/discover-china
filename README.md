# 🚂 山河之旅 (Discover China) — 线上版

中国地图火车旅行桌游《山河之旅》的线上 WebGL 实现。基于 **Three.js r128** 的单文件零构建依赖版本：50 城 83 边中国铁路网、5 色车票 + GO 万能票、无环全路径寻路与多路线选择、逐城分步跳跃动画、4K 离屏 Canvas 绘本底图（34 省真实省界、台湾/海南本岛、南海诸岛十段线附图框、定制矢量地标）。

> 机制还原自 Yaofish（鳐鳐鱼）实体桌游《山河之旅 / My First Journey》：每回合投掷 2 颗定制六面木骰（5 色 + GO! 万能票），沿铁路网消耗车票逐城移动，途经公共目标得分，先攒满 10 分并返回自己的秘密城市者获胜。

## 快速开始

直接用浏览器打开 `discover_china_3d.html` 即可游玩（`file://` 可运行，无需构建、无需安装）。

运行时需联网加载：
- Three.js r128（cdnjs 主源 + 字节 CDN 双容灾）
- 34 省 GeoJSON 省界（阿里云 DataV `100000_full.json`，加载成功自动叠加真实省界，失败回退手绘省界）

### 玩法

1. 所有玩家从**北京**出发；
2. 投两枚六面骰（红/黄/绿/青/紫 + GO 万能）获得车票（可囤积）；
3. 沿铁路网消耗车票逐城移动（支持多路线选择、单回合连续换乘、途经顺路抢分）；
4. 途经或停留任意公共目标城市即时得分并补牌；
5. 先攒满 **10 分**并抵达自己的**秘密城市**者获胜。

## 核心特性

- **拓扑**：50 城 / 83 边 5 色无向铁路网；叶子节点仅呼伦贝尔、佳木斯；济南、重庆为度数 5 枢纽；东南沿海海上虚线航线（沪-台-高-港-澳-琼）
- **寻路**：受限深度无环全路径枚举（签名去重、每城最多 8 方案、按耗票数升序与顺路得分降序排序），多路线弹窗选择 + 悬停预览
- **动画**：逐城分步跳跃（440ms/跳 + 110ms 停顿）、高空抛投 3D 木骰、2D/3D 视图一键切换
- **渲染**：4096×4096 离屏 Canvas 矢量绘本（MeshLambertMaterial 消除高光过曝）；台湾/海南本岛含岛内分界，右下角标准《南海诸岛》十段线附图框
- **交互**：手写内联球面阻尼相机；铁轨悬停原色微增 + 端点棋子半透明防遮挡透视；2D/3D 切换
- **AI**：启发式寻路（目标优先 → 顺路得分 → BFS 距离贪心），支持 2~4 人随时切换真人/AI，全员 AI 时手动启停
